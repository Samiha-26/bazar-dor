# বাজার দর / BazarDor

বাজার দর (BazarDor) is a beautifully designed, responsive web application built to help users effortlessly track the daily market prices of essential commodities in Bangladesh. With real-time price changes, interactive charts, and category-wise breakdowns, BazarDor ensures you never overpay for your daily groceries.

## Technologies Used

- **Framework**: Next.js (App Router, Server Components)
- **Styling**: Tailwind CSS & DaisyUI
- **Authentication**: Better Auth (Email/Password, Google, GitHub)
- **Database**: MongoDB
- **Notifications**: React Hot Toast
- **Icons**: React Icons / Custom SVGs
- **Deployment**: Vercel

## 5 Key Features

1. **Real-Time Price Tracking & Marquee**: Instantly view the day's top risers, fallers, and a continuous scrolling ticker of all commodity prices right on the homepage.
2. **Category & Sorting Controls**: Browse items categorically (Rice, Vegetables, Meat, etc.) and seamlessly sort them by price (Low to High, High to Low) utilizing native Bengali numeral support.
3. **Market-Specific Breakdowns**: Protected product detail pages show you minimum, maximum, and average prices across different markets and divisions in the country.
4. **Full Authentication System**: Robust, secure sign-in and sign-up flows using standard credentials or one-click OAuth (Google/GitHub) with Better Auth.
5. **Modern, Responsive Design**: A stunning, Figma-matched aesthetic featuring smooth skeleton loaders, responsive grids, and glassmorphism elements that look fantastic on mobile, tablet, and desktop.
